/plugin marketplace add gamercross/archi-board

• 설치 없이 지금 바로 브라우저에서 만들어 보려면 상단의 🛠 웹 스튜디오 탭을 여세요.
• 이미 묶은 board.single.html 파일을 스튜디오에 끌어다 놓으면 원본 board-data.js가 자동 추출됩니다.

앞면 — 처음 보는 사람 (5초 시험)

사용자 · 평가자 · 새 팀원이 보드를 열자마자 부품 이름과 코드 경로를 보면 길을 잃습니다. 앞면(layout: 'view' · layout: 'insight')은 코드 식별자 없이 쉬운 말로 ① 누가 쓰나 ② 무엇을 받나 ③ 어떤 차례로 도나 ④ 무엇이 받쳐 주나를 25개 안쪽의 상자로 보여 줍니다.

layout: 'view' (한 장 그림 · 차례 그림) layout: 'insight' (기준 · 값 · 근거 차트)

뒷면 — 만드는 사람 (코드 사실주의)

앞면 상자의 see를 누르면 만드는 사람 쪽으로 즉시 이어집니다. 코드에서 실제로 확인한 부품(objectMap), 저장소와 데이터 생명주기(dataMap), 장면마다 순서도 점이 함께 움직이는 유저 스토리(usecases[].story)가 한 장에서 맞물립니다.

layout: 'objects' · 'datamap' layout: 'ring' · 'rows' · 'cards' · 'time'

ArchiMate 6계층 상자 종류 (27 TYPES) — 클릭하면 스튜디오 코드 복사

모든 상자(elements)는 아래 27가지 표준 종류(t) 중 하나를 쓰며, 종류에 따라 층(색깔)과 귀퉁이 모양이 자동으로 정해집니다.

CLI & 커스텀 도메인 (archi-board.io) 안내

# 1. 데이터 무결성 점검 (브라우저 없이 실행)
node skills/archi-board/scripts/check.mjs docs/board/board-data.js

# 2. 오프라인·아티팩트용 단일 HTML 묶기
node skills/archi-board/scripts/inline.mjs docs/board

# 3. 묶은 HTML에서 board-data.js 다시 꺼내기
node skills/archi-board/scripts/unpack.mjs board.single.html ./out

# 4. 루트 index.html (archi-board.io) 빌드 및 점검
node tools/build-showcase.mjs
node tools/build-showcase.mjs --check

GitHub Pages 도메인 연결: 도메인 등록 후 저장소 Settings → Pages → Custom domain에 archi-board.io를 입력하면 이 스튜디오와 엔진(/engine/v1/)이 그대로 호스팅됩니다.
